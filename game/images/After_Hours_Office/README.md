# Shyvirelle: After Hours Office

## English

A contemporary office suite in slate blue, walnut and brushed metal, with reception, a meeting room and a manager office.

**Contents:** 6 original RGB PNGs, 3 locations with day/night variants; native resolution 1672 × 941 px (approximately 16:9), manifest, commercial-use license, offline HTML preview and a small Ren'Py integration example. Static flattened backgrounds. No character sprites, animation, music or layered project files.

1. Extract the whole ZIP before opening `preview.html` in a browser. You do not need to install an image generator to view or use the PNGs.
2. Import the PNG files into the background layer of your engine. Add your own characters and dialogue on top. Files can be resized or cropped for your project.
3. For Ren'Py, copy this pack's `images` folder into `game/images/shy_office`, and copy `example_RenPy.rpy` into `game/`. Add `call shy_office_demo` inside an existing label to run the demonstration. Do not replace your existing `label start`. The example scales images at runtime to the configured screen size; use a similar aspect ratio to minimize distortion.

The Ren'Py example has been checked for paths and against official syntax documentation; it has not been executed in Ren'Py. The HTML preview is a separate browser demonstration, not a Ren'Py game.

**AI disclosure:** graphics were generated with AI and selected/visually reviewed. Supporting text and example code were also created with AI assistance. No custom model training was used. Minor generative details may remain; inspect the full-size PNGs for your intended use. Credit is optional; see LICENSE.md.

## Español

**Qué compra el usuario:** tres escenarios del mismo lugar, cada uno de día y de noche: seis archivos. Puede colocarlos detrás de sus personajes en un juego o novela visual y vender su obra bajo la licencia incluida. No son páginas de manga terminadas ni un juego completo.

**Cómo verlos:** descomprime el ZIP y abre `preview.html`. Los botones cambian el escenario y la iluminación. El diálogo y la guía de personaje son superposiciones de demostración, no forman parte de los PNG. Para usarlos, importa los archivos de `images` a tu motor.

**Resolución real:** 1672 × 941 px. No se anuncian como 1080p ni 4K nativos. Se preservaron los originales generados. Es un producto realizado con IA; no requiere que el comprador entrene o descargue un modelo.
